# v0.2.0 — Curated data sources and limitations

This is a **small, evidence-backed candidate shortlist**, not a complete BiS database and **not a gear simulator**. Rankings are tentative and depend on talents, weapons, set bonuses, consumables, hit cap, and acquisition conditions. Items listed across Ring 1/2 or Trinket 1/2 are **alternatives for each slot**, not an instruction to wear two copies of a unique item.

## Progressive Vanilla schedule

The addon uses seven UI stages. Stage 1 (Pre-Raid) is a *gear category*, not a claim that raids were unavailable on release. Stage 2 (Molten Core/Onyxia) adds initial raids, Stage 3 (Dire Maul/World Bosses + honor/AV/WSG) represents the next unlock group before BWL, Stage 4 is BWL, Stage 5 adds Zul'Gurub/Arathi Basin, Stage 6 adds AQ, Stage 7 adds Naxxramas.

**Historical caution:** original Vanilla patch release order, WoW Classic 2019 phases and their early-release exceptions are not identical. This version groups several subpatch unlocks; it does not yet provide literal patch-by-patch dates. Source: Blizzard timeline [official Classic phase plan](https://us.forums.blizzard.com/en/wow/t/everything-we-definitively-know-about-classic/25299/1), [2019 phased schedule](https://www.wowhead.com/guide/wow-classic-six-content-phases), [comparison](https://us.forums.blizzard.com/en/wow/t/timeline-vanilla-vs-classic-releases/569660).

## Known limitations

- Only Combat Rogue (primarily swords) and Enhancement Shaman have an initial partial recommendation shortlist. Some raid upgrades are omitted until detailed validation, so an earlier listed candidate may no longer be true BiS.
- Shaman recommendations assume Horde and the original 1.12 class restrictions. As future race-specific talent and weapon-skill recommendations are added, race restrictions must be modeled per item/selection.
- Grouped patch stages are simplified. Some pre-raid items in later patch dungeon loot tables must be separately verified for accurate historical unlocks before expansion.
- Item links use original item IDs and rely on the game client's item cache for mouseover tooltips. Clicking shows name, ID and source in chat.
- PvP gear is opt-in and still phase-locked, currently represented by Don Julio's Band.
- Set synergy and unique-equipped conflicts are documented but not simulated; do not interpret mirrored ring and trinket slots as a valid complete gear set.
